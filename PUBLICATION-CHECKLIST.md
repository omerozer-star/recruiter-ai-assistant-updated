# Public Repository Checklist

Complete this review before making the repository public and before every subsequent release:

- [ ] No `.env` file, API key, access token, password, or credential is included.
- [ ] No `*.db` file, database export, backup, or operational dataset is included.
- [ ] No browser profile, cookie, authenticated session, QR code, or account identity file is included.
- [ ] No phone number, email address, contact name, candidate information, or other personal data is included.
- [ ] No personal Facebook or WhatsApp URL, private group link, or invitation link is included.
- [ ] No private job listing, application URL, company name, or unapproved branded asset is included.
- [ ] Any sample or demo data is fictional or explicitly authorized for publication.
- [ ] `git status` contains only files that have been reviewed manually.
- [ ] The staged changes have been scanned for secrets and unexpectedly large files.
- [ ] Connected services and automation workflows have been reviewed for authorization and terms-of-service compliance.
- [ ] The `LICENSE` file (MIT) is present and the README license section matches it.
- [ ] Repository visibility, collaborators, branch rules, and security settings have been reviewed on GitHub.
